# 08 Shell 细则

## 1. 文件名头要求

- `.sh` 首行为 shebang(`#!/usr/bin/env bash`), 第二行起写 `#` 注释块, 逐行写八栏。
- 注释块除八栏外必须写四项: 输入(位置参数与环境变量, 含默认值与是否必填)、退出码(0 与各非零含义)、依赖命令(命令名与最低版本)、运行平台。
- `.ps1` 用 `<# #>` 块注释同样写八栏与上述四项, 并用 `#Requires` 声明 PowerShell 版本。
- 禁止在文件头写作者、日期、变更记录。
- 一个脚本一个主要职责; 需要多职责时拆分为多个脚本或加子命令。

## 2. 依赖引入区要求

- bash 的 `source` 与 PowerShell 的点引入 `.` 必须行尾注释来源与用途; 引入路径用脚本自身目录推导, 不依赖调用者工作目录。
- 外部命令依赖在文件头「依赖命令」栏列全, 运行前用 `command -v` / `Get-Command` 校验, 缺失时给出可判定报错与非零退出。
- 禁止引入来源不明的远程脚本; 禁止 `curl | bash` 与等价的远程管道执行。下载与执行必须分离, 执行前校验来源与哈希。
- 环境变量在使用前集中校验, 缺必填项立即失败并打印缺失项名称。

## 3. 类型与函数注释要求

- 每个函数上方写注释: 用途、参数(名称/含义/默认值/必填性)、返回值与副作用、退出码、失败时的输出。
- 全局变量写用途与作用域; 环境变量标明是否必需与默认值。
- 含多个公开函数的脚本在文件头注释块中写「方法一览」, 形式为每行 `#   pick <name> <response> [default] -> 0/1: 一句话用途`; 仅作速查, 参数与退出码写在函数自己的注释里。
- 必须写「为什么」: 特殊参数选择的理由、为何需要 `local`、为何重定向到标准错误、为何忽略某命令失败。
- 必须 `set -euo pipefail`; PowerShell 必须设 `$ErrorActionPreference = 'Stop'` 并逐步检查 `$LASTEXITCODE`。缺失即不合格。
- 禁止用注释替代失败处理: 说明「失败可忽略」必须在代码里显式处理并写明理由。

## 4. 行尾注释判据

- 只写原因不写翻译; 判据同总则。
- 本语言必写情形:
  - `set +e` 段落的原因与恢复点。
  - `|| true` 的理由与后续如何判定真实失败。
  - `2>/dev/null` 的理由与被吞掉的错误类型。
  - `rm -rf` 的目标来源与保护条件。
  - 临时文件与清理钩子的执行时机。
  - 平台分支(`uname`、`$IsWindows`)的理由。
  - 路径与变量刻意不加引号的理由; 无理由必须加引号。
- 免写情形: 显然的 `echo`、变量赋值、简单条件判断。
- 裁定结果按总则写入本节, 以案例沉淀。

## 5. 分区标记

- 形式: `# =========** 名称 =========**`。
- 标记下一行必须是该分区首行的注释或一行职责说明; 标记本身不写职责说明。
- 分区顺序: 常量与默认值 -> 参数校验 -> 函数 -> 主流程 -> 清理。
- 清理逻辑必须在主流程之外单独成区, 并注册退出钩子。

## 6. 标点与空格

- 注释内标点一律半角; 中文与英文或数字之间留一个空格。
- 全角标点只允许出现在面向用户的字符串字面量内; 注释中禁用书名号与直角引号, 改用半角引号。
- 日志与错误信息中的占位符统一形式, 例 `name=%s`, 不混用多种风格。

## 7. 违规范例(一条)

```bash
# 不合格示例: 无 set -euo pipefail, 参数未加引号, 远程管道执行
curl -fsSL https://example.com/install.sh | bash
```

问题:

- 缺失败即停, 中间步骤失败仍会继续。
- 下载与执行耦合在同一管道, 无法校验来源与哈希。
- 未写依赖命令与退出码, 调用方无法判定结果。

## 8. 交付前自检清单

- [ ] shebang 与八栏注释块齐全, 含输入、退出码、依赖命令、运行平台。
- [ ] `set -euo pipefail` 存在, 或 PowerShell 的等价设置齐全。
- [ ] 无 `curl | bash` 类远程管道执行。
- [ ] 每个函数有用途、参数、退出码注释。
- [ ] 含多个公开函数的脚本写了「方法一览」。
- [ ] 路径与变量引用已加引号, 例外处写明理由。
- [ ] 重定向与忽略失败均有行尾理由。
- [ ] `shellcheck` 无告警, 或告警已按误报流程登记。
