## 三、已知约束

| 约束 | 影响 |
| --- | --- |
| 内存 2 GiB | C++ 与 Rust 的完整构建容易触发 OOM。重编译类任务须改为本地构建后只传产物，或临时开 swap 并接受耗时上升。 |
| 出网 3 Mbps，约 0.38 MB/s | 制品分发、自更新包体、镜像拉取均受此上限约束，包体大小需按带宽倒推。 |
| Ubuntu 20.04 已过标准支持期（2025 年上半年到期，现依赖 ESM） | 新装环境建议 22.04 或 24.04，20.04 仅作存量维护。 |
| 合规：备案备注写明"不开展商业用途" | 若产品涉及收费、广告或对外开放注册，须先变更备案性质。 |
